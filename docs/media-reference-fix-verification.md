## 实际改动

- 参考图读取优先使用已有 IndexedDB 原图；读取失败显示明确错误。画布普通生成、内置面板和重试的准备阶段均进入 try/finally，并传递取消信号。
- 已确认的平台公开模型采用独立合同：26 个图片名称、24 个视频名称/别名。拉取模型后的能力猜测补齐 Gemini Banana、MiniMax H3、带连字符的 Seedance 与 FK 别名；不覆盖用户已有分类或显式脚本。
- FK 图片传 imageSize/ratio，易红 GPT 使用精确尺寸、Gemini 使用 imageSize/ratio。参数面板跟随合同；自定义非法尺寸、时长、参考上限在提交前拒绝，不默默裁剪。直连 OpenAI gpt-image 仍省略 response_format。
- FK、小易与易红当前视频型号均使用现有 upload-url 授权合同直传 OSS，再按各自合同发 JSON；FK 的旧版本文件路径已被上述 OSS＋JSON 替代。平台 Token 只发给自己的 NewAPI，OSS 请求不带该 Token/Cookie；上传失败不提交生成。
- 小易单图、易红普通参考、Super/Prime media、H3 attachments 与 Grok 字段分别组装。必要的参考媒体时长在上传前检查；不支持的首尾帧组合拒绝，不改成其它语义。
- 已知平台视频绕开不匹配的旧内置脚本，创建后保存真实任务 ID、原模型与渠道地址；刷新续查原任务，原渠道缺失/地址变化会报错，不自动换渠道。原 Super/Cheap 内置脚本的 40 分钟、5 秒间隔轮询预算保留，其余路径沿原策略；未新增重生成重试。
- 平台完成的视频取鉴权 content 字节；失败状态不会因残留 URL 被标成功。视频必须能解码并写入本地，拒绝 HTML/JSON/空内容假成功，取消贯穿下载与保存。
- 生成图片采用严格本地保存，不再以展示外链冒充保存成功。画布结果与生图工作台保存失败时保留来源，重试仅保存；节点插件宿主在页面内保留失败保存的结果，重复同一调用先保存已有结果，不重生成。这个宿主缓存不是刷新恢复能力。
- 图片/视频下载优先使用本地原始 Blob，不取缩略图。保存重试后保持原始图片比例。
- 按用户确认，仅交互新选模型时填入已核实的默认时长：小易 6 秒；FK 六类新视频依次 30/15/30/4/15/4 秒（来自现有 App 能力目录）；易红按插件 defaultSeconds。已有节点、同一模型重复选择、历史恢复、其它渠道与用户自定义脚本不被自动改写。画布配置/视频节点和视频工作台的模型选择入口均已接入。
- 已知平台视频新增轻量阶段提示：读取参考素材、上传素材、创建任务、生成中、获取结果、保存到本地。配置节点停止按钮与结果节点加载区复用原主题显示，不引入新状态机。

## 浏览器实测（合成素材）

开发服务仅监听 `127.0.0.1:3000`；独立夹具服务 `127.0.0.1:3002`。启动夹具：

```sh
bun tests/media-fixture-server.ts
```

访问 `http://127.0.0.1:3000/tests/media-browser-fixture.html`，点击相应测试按钮。仅创建自己的测试图片/视频和可选隔离测试项目、独立夹具渠道，不清理任何现有项目或用户渠道。

实测通过：跨域图片可以展示但 fetch 被浏览器拦截；本地原图优先读取；真实 IndexedDB 保存尺寸与原始字节；立即取消被拒；严格保存无法读取的外链时失败。刷新后原图可恢复。合成 MP4 的真实解码尺寸为 32×32、时长 1 秒，视频入库后刷新仍能恢复；HTML 不会成为保存成功的视频。

追加故障注入：在独立测试页临时让 image_files 写入抛 QuotaExceededError，失败后保留同一结果；恢复存储后成功保存，夹具计数确认图片生成 POST 只有一次，原有测试原图未被清理。没有填满磁盘或删除用户数据。

真实画布视频续查：独立画布调用本地夹具创建 queued 任务，生成途中刷新后继续查询同一 ID；夹具切至 completed 后成功保存本地 Blob、真实解码尺寸 32×32。全过程视频创建 POST 只有一次，完成内容 GET 一次；点击画布“下载视频”后，下载文件与 tiny.mp4 的 SHA-256 均为 `9c1506e68424d8d01f14c6bdb97af436da9fc092e9f8916dfac564a392a00453`。此测试验证画布创建/恢复/下载链路，不代替三个生产插件的收费验收。

真实画布配置节点连接仅可展示的跨域图后点击生成，显示“读取参考图片失败，请重新上传原图或检查素材跨域权限”，“开始生成”按钮恢复可用。此路径只连接本地夹具，不连接真实计费平台。
